Any2Odd

Continuous desktop 3D for the Samsung Odyssey G90XF. Version 0.5.0.

Open the bright yellow glasses icon to start. Whole desktop + AI conversion is the default: wallpaper, icons, windows and compatible borderless games stay in 3D until you turn it off.

Everyday controls

ActionControl
3D on/offRight-click tray icon, or Ctrl+Alt+F10
Open controlsDouble-click tray icon, desktop shortcut, or Ctrl+Alt+F9
Restore overlay without taking game focusCtrl+Alt+F8
Exit completelyTray menu → Quit

Closing/minimizing normally sends Any2Odd to the tray. Change “Minimize and close to the tray” if you prefer normal taskbar behavior. The taskbar icon's right-click jump list includes toggle and controls commands. Escape remains available to your game.

Settings

  • Whole desktop: recommended for direct interaction. Mouse and keyboard input reach the underlying desktop/game.
  • Selected window / Follow active window: experimental fitted-window views; scaled mouse coordinates are not remapped.
  • AI: converts ordinary 2D content automatically.
  • Side-by-side: manually select for content already containing a stereo pair. Automatic stereo-layout detection is not implemented.
  • Depth and pop-out: adjust sliders and Apply. The converter restarts briefly.
  • Keep 3D above apps: maintains the overlay without taking keyboard focus.
  • Convert automatically: starts 3D when Any2Odd opens. This is not a Windows sign-in startup setting.

Requirements

Tested with G90XF as primary display at 3840 × 2160 landscape, RTX 4090, Windows 11, Odyssey 3D Hub 1.5.1 and its installed LeiaSR software. Windows 11 24H2+ is required. Keep DisplayPort and USB upstream connected; the monitor's stereo camera must work. This release checks a specific Samsung engine hash and uses an RTX 4090 core-count hint. Other GPUs and engine builds are unvalidated.

If something looks wrong

  • Turn 3D off with Ctrl+Alt+F10 to return to the normal desktop.
  • Use windowed/borderless games and stop Samsung's separate conversion player.
  • Check USB/camera detection, resolution and primary display if conversion does not start.
  • Use Ctrl+Alt+F8 if the output goes behind another app.
  • Enable taskbar auto-hide in Windows. Other apps' attention requests can still hold it open.
  • A yellow capture indicator can appear if Windows denies borderless capture access.
  • AI conversion adds latency; protected video, secure desktops and exclusive fullscreen may not capture. HDR input is normalized to SDR, not rendered in native HDR.

Files and uninstall

Existing settings remain under %LOCALAPPDATA%\Odyssey3DCompanion. Internal paths retain the former Companion name for upgrade compatibility. Open View logs to inspect local diagnostics; redact private paths/window titles before sharing them.

Uninstall Any2Odd through Windows Installed apps. Samsung's original binaries are not patched. Your settings, logs and the original Samsung overlay-settings backup remain; uninstall does not overwrite newer Samsung preferences with the backup. No computer restart is needed.
